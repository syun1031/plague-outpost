# 暗疫陣地（暫定名）

一款推理小遊戲，玩起來像數獨。人類遇上一種看不出病徵的病毒，你是陣地指揮官，要根據隊員的專長回報，找出所有感染者。

## 玩法
- 盤面是 m×n 的格子。**列**＝橫排，用數字 1、2… 表示；**行**＝直排，用字母 A、B… 表示。
- 感染者的總數一開始就告訴你，而且答案只有一種（產生器會用解題器確認）。
- 有專長的隊員一定健康，他們的回報一定正確。
- 點擊隊員會播放機械動作，並用紅光顯示技能範圍；再點一次就收回。
- 「標記感染／標記健康」只是幫你整理推理。所有感染者都標記正確時，就自動處決並獲勝。
- 也可以先處決已標記的感染者。分散的人用手槍處決，相鄰（含斜角）聚在一起的用爆破處決。只要誤殺一個健康的人就失敗。

## 難度與模式
- **簡單**：每一步只靠單一線索就能推出。
- **普通**：需要比對兩條線索（一條的範圍包含另一條，兩者相減）。
- **困難**：上面兩種方法解不完，需要假設與排除。答案仍然唯一。
- **一般模式**：所有感染者都標記正確就勝利，剩下的人會自動處決。
- **硬派模式**：標記不會觸發勝利，必須親手處決全部感染者。
- **今日任務**：固定 5×5 普通難度，以台灣日期當種子，同一天所有人玩到同一題。最快紀錄存在瀏覽器裡。

## 本機執行
這是純靜態網頁，不需要建置。因為用了 ES modules，必須透過本機伺服器開啟，不能直接雙擊檔案：
```
python -m http.server 5173
```
開啟 http://localhost:5173

## 專案結構
- `js/puzzle.js`：線索規則、解題器（計算解的數量）、模擬玩家的邏輯解題器、依難度產生唯一解謎題
- `js/art.js`：俯視角角色與標記圖示（內嵌 SVG）
- `js/commander.js`：男女指揮官立繪，含四種表情
- `js/fx.js`：Canvas 特效，包含手槍、爆炸、勝利、失敗
- `js/audio.js`：WebAudio 合成音效
- `js/main.js`：遊戲流程與介面
- `favicon.svg`、`favicon-32.png`、`apple-touch-icon.png`：網頁圖示（PNG 由 `python tools/make_icons.py` 產生）

## 部署
上傳到 GitHub 後，在 Vercel 匯入這個 repo，Framework 選「Other」，不需要 Build Command，輸出目錄用根目錄即可。
